# New Leaf CRM — online demo

This repository publishes the **in-browser demo** of the New Leaf University Admission CRM to https://new-leaf-crm.vercel.app

- Sample data only. Anything entered stays in the visitor's own browser and is not shared.
- Demo sign-in: `superadmin` / `Demo@123` (and the other role chips on the login screen).
- Do not enter real student data here.

The full CRM (Node server + database) lives in the main project and is not part of this repository.
To update this demo, copy `index.html`, `runtime-config.js` and `src/` from the main project and push.
